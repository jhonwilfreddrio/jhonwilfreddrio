Problem

Applying for a Bureau of Internal Revenue Computerized Accounting System permit requires gapless serialized documents, books of accounts, and an audit trail that cannot be edited — even by someone with database access.

What I Built

Sales Invoice with the required face, per-series gapless numbering, senior-citizen and PWD tax-exempt math, void-not-edit with reprint marking, and a specimen print mode. The full six-document set (invoice, collection receipt, credit and debit memo, purchase order, receiving report), a chart of accounts, journal with a database-level balance constraint, general ledger, trial balance, and sales journal. Result

The audit log is append-only at the database level, an audit viewer supports filters, print, and CSV export, and marketplace payout files reconcile against the books. Built as a parallel module, so inventory, orders, and finance behaved exactly the same the day it shipped.

// guardrails

Rules KORA cannot break

  • Identity is enforced in code. Identity questions get a fixed reply, and every model answer is scanned for foreign self-identification before it is sent.
  • Private stays private. Sales figures and system errors go to configured private recipients; the group only sees operations and sanitized snapshots.
  • Owner-only commands. Work-log and away-mode commands answer only to one account, on top of an optional allowlist for everything else.
  • Sanitized developer feed. Report items are scrubbed of control characters, secret-looking values, and private file paths before they are accepted.
  • Idempotent by design. Each report item carries a stable work ID: exact repeats are acknowledged, conflicting reuse is rejected with HTTP 409.
  • Fail closed. Malformed or wrong-date feed data stops the report build instead of sending a partial report.
  • Delivery is evidence. The "delivered" marker is saved only after a successful group send, so nothing is claimed that did not happen.
  • The model is an adviser. Local AI calls run on-premise with bounded timeouts; system authority stays in verified ERP data.
